## 这个项目解决什么问题

YuE2 是 M-A-P 团队开源的音乐生成大模型（3B 参数），输入一段**风格描述**和**歌词**，就能生成带人声的完整歌曲。但官方只提供了命令行和一份研究用的演示页：

- 参数藏在 `yue2.protocol` 里，没有界面；
- 官方要求 24 GB 显存，8 GB 笔记本直接跑不了；
- 演示页是「研究画廊」，只有 4 个筛选器，不是给创作者用的工具。

这个项目做三件事：

1. **做一个真正给创作者用的图形界面**——中文、卡片式、三步出歌，高级参数收在「高级设置」里，新手不会被吓到。
2. **让小显存也能跑**——内置「内存扩展模式」（`ram_mode.py`），把当前用不到的模型权重按阶段在内存和显存之间搬运，实测 **8 GB 显卡也能生成 3 分钟以上的完整歌曲**。
3. **给足创作自由度**——26 种乐器（含 8 种中国民族乐器）、合奏编制、采样参数、规划档位、外部乐谱（ABC 谱）回填，外加「一次出 1/2/4 首」挑着听。

## 功能特性

- 🎯 **三步出歌**：选风格 → 写歌词 → 点生成，浏览器自动打开播放。
- 🖥️ **小显存支持**：8 GB 显卡自动启用内存扩展模式；显存越大跑得越快，无需手动配置。
- 🌏 **全中文界面**，内置 13 套风格预设（中文流行、粤语抒情、中国风、日系 City Pop、爵士、民谣……）。
- 🎵 **26 种乐器 + 合奏编制**：含古琴、古筝，琵琶，二胡，竹笛，洞箫，笙，阮，以及琴箫合奏 / 筝笛合奏 / 筝琵合奏 / 丝竹乐合奏。
- 🎚️ **完整创作参数**：采样温度、top_p、top_k、重复抑制、ODE 步数、CFG 强度、随机种子、规划档位（off / melody / full）、外部 ABC 乐谱。
- 📦 **批量生成**：一次出 1 / 2 / 4 首，参数完全一样、只换种子，方便挑满意的版本。
- 💾 **一键下载**：生成无损 FLAC；机器装了 ffmpeg 还会多一个 MP3 下载按钮，方便发微信。
- 🔁 **历史作品**：界面内可回听最近 8 首，不用切文件夹。
- ☁️ **云 GPU 部署**：`pack.py` 一键打包源码（约 200 KB），丢到云主机 `install.sh` + `start.sh --cloud` 即可用。
- 🧪 **自带验证脚本**：`selftest.py` 自检环境；`benchmark.py` 压测长歌；`verify_*.py` / `verify_ui.js` 校验参数与界面。

## 界面长什么样

界面是五张卡片：

1. **选风格**——预设一键填入，或点「组合器」自由拼语言 / 流派 / 人声 / 情绪 / 乐器 / 调性 / 拍号 / BPM。
2. **填歌词**——按 `[Verse]` / `[Chorus]` / `[Bridge]` / `[Outro]` 分段；纯音乐填 `[Instrumental]`。
3. **规划方式**——`cot` 三档（完整规划 / 旋律规划 / 直接生成）。
4. **创作风格**——把采样、ODE 步数、CFG、种子收在「高级设置」里，默认收起。
5. **时长上限**——按硬件能力自动给上限（8 GB 档默认 240 秒）。

底部状态栏固定四行：显卡 / 显存 / 内存 / 运行模式。

## 硬件要求

| 项目 | 要求 |
|------|------|
| **显卡** | **必须 NVIDIA（CUDA）**。AMD / 核显 / Apple 芯片无法跑推理。 |
| **显存** | 8 GB 起可用（启用内存扩展模式）；≥14 GB 标准模式；≥20 GB 全速。 |
| **内存** | 建议 ≥16 GB。8 GB 显存档生成时内存会当显存用，可用内存别低于 4 GB。 |
| **硬盘** | 约 15 GB 空闲（模型权重约 7.8 GB + 环境 + 输出）。 |
| **系统** | Windows 10/11，或 Linux（云 GPU 常见）。macOS 未测试。 |
| **Python** | 3.10 及以上（安装脚本会自动找，找不到会提示去装）。 |

显存分档（实测，非官方文档）：

- **≥20 GB**：完整模式全速。
- **≥14 GB**：标准模式。
- **≥8 GB**：自动启用内存扩展模式，实测峰值显存约 5.7 GiB，可生成完整歌曲。
- **6–8 GB**：内存扩展 + 自动切旋律模式，建议 2 分钟以内。
- **<6 GB**：只能试很短的片段，大概率失败。

## 快速开始

### Windows（最省事）

1. 双击 **`install.bat`** → 自动建环境、装 PyTorch(CUDA)、下模型（约 7.8 GB），全程 10–20 分钟，中途别关窗口。
2. 双击 **`start.bat`** → 浏览器自动打开 `http://127.0.0.1:7861/`。
3. 选一个风格预设，写几句歌词，点「生成歌曲」。

> 第一次生成会先加载模型 + CUDA 预热，比后续慢一些（见[性能实测](#性能实测rtx-4070-笔记本-8gb)）。保持窗口开着，关掉就退出。

### Linux / 云 GPU

```bash
chmod +x install.sh start.sh
./install.sh        # 建环境 + 装依赖 + 下模型
./start.sh          # 本机用，监听 127.0.0.1
# 云主机对外暴露：
./start.sh --cloud  # 监听 0.0.0.0（建议用 SSH 隧道访问，别直接公网暴露）
```

## 安装详解

`install.bat` / `install.sh` 做四件事（已完成的步骤重跑会自动跳过）：

1. **检查 Python**：需要 3.10+，否则提示去 python.org 装。
2. **建独立环境**：在程序目录里建 `.venv`，不污染系统，并切到清华 pip 镜像。
3. **装依赖**：
   - PyTorch 2.10.0 (CUDA 12.8)，约 2.9 GB。国内直连官方 CDN 极慢，脚本按顺序试上海交大 / 阿里镜像（实测 56 MB/s），并校验 zip 完整性，截断的下载会被识别重下。
   - YuE2 推理包 `yue2_infer` wheel（从 `hf-mirror.com` 下载，已伪装浏览器 UA 绕过 403）。
   - 界面附加依赖 `huggingface-hub`。
4. **下载模型权重**（约 7.8 GB）：从 `hf-mirror.com` 按清单逐个拉 `YuE2-3B` 和 `YuE2-Vae`，跳过 `assets/`、`examples/` 等推理用不到的演示素材。**本机直连 huggingface.co 不通，脚本已强制走镜像。**

下载中断没关系，重跑脚本会续传。

> 想重新安装：Windows 加 `--force` 重跑 `install.bat`；Linux 删掉 `.installed` 标记或重跑 `install.sh`。

## 使用方法

### 1. 选风格

直接点一套预设，风格框和歌词框会自动填好。想自己来就清空，用「组合器」自由拼。

### 2. 写歌词

按段落标签写，模型认这些标签：

```
[Verse]
路灯把影子拉得很长
我数着回家的方向

[Chorus]
如果风也会说话
它会替我说想你啊

[Bridge]
一年又一年
我把心事折成纸船

[Outro]
风还在吹
我还在这里
```

- **纯音乐**：歌词框填 `[Instrumental]`（注意大小写和方括号），人声轨会自动留白。
- **歌曲长度由歌词决定**，不是时长选项。实测一段约唱 15 秒；歌词短了模型会自然收尾。时长滑块只是「上限」。

### 3. 点生成

点「生成歌曲」，状态栏实时显示阶段（加载 / 规划 / 语义生成 / 合成 / 解码）。完成后直接在线播放，点「下载音频文件」存到本地。

> 输出是无损 **FLAC**（音质最好，但微信 / 部分手机不认）。**装了 ffmpeg** 会自动多一个「下载 MP3」按钮，方便分享。

## 创作参数详解

点「高级设置」展开。所有参数在入口处都会夹到合法区间，坏值退回默认，不会让整次生成崩掉。

### 采样（决定「发散度 / 创造性」）

| 参数 | 范围 | 默认 | 说明 |
|------|------|------|------|
| `temperature` | 0.0–5.0 | 1.0 | 越高越发散、越有惊喜；越低越保守、越像训练分布。 |
| `top_p` | 0.01–1.0 | 0.95 | 每步只从累计概率前 p 的音里挑。 |
| `top_k` | 1–500 | 100 | 每步只从概率最高的前 k 个音里挑。 |
| `repetition_penalty` | 1.0–2.0 | 1.2 | 重复抑制强度，越高越不重复。 |
| `penalty_window` | 1–100 | 50 | 重复抑制往前看多少个音。 |

> 想要稳妥好听：温度 0.8–1.0。想要离谱一点：温度 1.3+，top_k 调小到 40–60。

### ODE 步数（`ode_steps`）

可选 **16 / 32 / 48**，默认 32。步数越多细节越足、越慢。32 是质量/速度的甜点。

### CFG 强度（`cfg_scale`）

0–20，留空 = 用官方默认（完整规划 1.0，直接生成 1.01）。越大越「听话」、越贴风格描述，过大易失真。

### 规划档位（`cot`）

对应官方页的「With symbolic planning / Direct generation」：

- **off（直接生成）**：最快，不产出乐谱。10 秒音频约 63 秒（规划阶段单独吃 30–45 秒）。
- **melody（旋律规划）**：先规划旋律再生成。
- **full（完整规划）**：先出 ABC 乐谱再生成，最稳但最慢。

### 随机种子（`seed`）

留空 = 随机。固定种子 = 可复现同一首。批量生成时每首种子自动 +1。

### 外部乐谱（ABC 谱）

在「高级设置」里贴一段 ABC 记谱法文本，模型会照着它生成（此时 `cot` 自动抬到 full）。生成后界面「查看乐谱」能看到模型自己写的 `score.abc`，并支持**一键回填成外部乐谱**继续改。

## 自由创作：组合器与中国风乐器

点风格框下方的「组合器」可自由拼维度（写法）：
**语言（6）× 流派（50）× 人声（4）× 情绪（7）× 乐器（26，最多 4 件）× 调性（13）× 拍号（7）× BPM（60–180）**。

乐器含 8 种中国民族乐器：**古琴、古筝、琵琶、二胡、竹笛、洞箫、笙、阮**。
另有「合奏编制」下拉，一键套：

- **琴箫合奏**（古琴 + 洞箫）
- **筝笛合奏**（古筝 + 竹笛）
- **筝琵合奏**（古筝 + 琵琶）
- **丝竹乐合奏**（古琴 + 古筝 + 琵琶 + 竹笛）

> 实测笔记：纯器乐提示词**生效**（人声轨自动留白），适合做中国风纯音乐。但模型对「中国风调式（如五声音阶）」的约束**不严格**，产出的调式未必是标准五声，介意的话可手动贴 ABC 谱指定调式。

## 一次出多首（批量生成）

生成按钮上方有「一次出 1 / 2 / 4 首」：

- 参数完全一样，只有**种子逐个递增**，方便挑满意的版本。
- 总耗时约等于单首 × 数量（2 首≈2 倍，4 首≈4 倍）。
- 完成后结果区列出每首的时长 / 耗时 / 种子，各自独立播放、下载。

## 开发者：HTTP API

`app.py` 是一个自带的前端 + 后端（`ThreadingHTTPServer`，默认 `127.0.0.1:7861`）。环境变量：

- `YUE2_PORT`：端口，默认 `7861`。
- `YUE2_BIND`：`0.0.0.0` 监听所有网卡（云模式）。
- `YUE2_NO_BROWSER`：`1` 时不自动开浏览器。

端点：

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/` | 界面 |
| GET | `/api/status` | 硬件 / 显存 / 内存 / 运行模式 |
| GET | `/api/job` | 当前任务状态（进度、阶段、种子、批量信息） |
| GET | `/api/history` | 最近 8 首历史 |
| GET | `/api/audio?dir=<目录>` | 取音频（加 `&download=1` 触发下载） |
| GET | `/api/score?dir=<目录>` | 取该首的 `score.abc` |
| POST | `/api/generate` | 提交生成：`{style, lyrics, seconds, seed, count, options}` |

每次生成的落盘元数据在 `outputs/<目录>/config.json` 和 `request.json`，是验证参数是否真传到推理层的最佳手段。

## 云 GPU / 远程部署

1. 本机跑 `python pack.py` 生成 `YuE2-GUI-upload.zip`（只含源码，约 200 KB，不含模型/环境）。
2. 上传到云主机，解压：
   ```bash
   unzip YuE2-GUI-upload.zip
   cd YuE2-GUI
   chmod +x install.sh start.sh
   ./install.sh
   ./start.sh --cloud
   ```
3. **安全建议**：别直接把 7861 端口公网暴露。用 SSH 隧道：
   ```bash
   ssh -L 7861:127.0.0.1:7861 <user>@<host>
   ```
   然后本机浏览器开 `http://127.0.0.1:7861/`。

## 性能实测（RTX 4070 笔记本 8GB）

实测硬件：RTX 4070 Laptop **8 GB** 显存 + 16 GB 内存，启用内存扩展模式。

| 目标 | 实际产出 | 峰值显存 | 总耗时 | 内存最低可用 |
|------|----------|----------|--------|--------------|
| 177 秒 | 177.0 秒（自然收尾） | 5.15 GiB | 7.7 分钟 | — |
| 240 秒 | 221.3 秒（自然收尾） | 5.54 GiB | 10.2 分钟 | 0.47 GB |

要点：

- **歌曲长度由歌词决定**，只调大 `max_tokens` 没用；压测长歌必须先把歌词铺够（见 `benchmark.py` 的 `build_lyrics`）。
- **第一次生成有冷启动开销**（模型加载 + CUDA 预热，约数百秒），后续显著变快。测速请先热身。
- 纯器乐与带人声速度同量级（热启动约 0.16 秒/语义令牌），不是慢 5 倍。
- **连续两次生成无劣化**：说明内存扩展模式在生成结束把模型搬回 CPU 后状态机能正确复位。

## 常见问题（FAQ）

**Q：点开界面提示「Not installed yet」？**
A：先双击 `install.bat`（Windows）或 `./install.sh`（Linux）装环境和模型。

**Q：显存不够 / 只有 8 GB 能跑吗？**
A：能。8 GB 会自动启用内存扩展模式，用内存当显存。生成前关掉浏览器、聊天软件，保证可用内存 ≥4 GB 最稳。

**Q：为什么生成的歌比设定的时长短？**
A：时长只是上限，歌长由歌词决定。歌词写短了模型会自然收尾。想更长就多写几段。

**Q：没有 N 卡（AMD / 核显 / Mac）能跑吗？**
A：不能，YuE2 推理强依赖 CUDA。可以装完把整个文件夹搬到有 N 卡的机器上用。

**Q：下载模型老是中断 / 403？**
A：脚本已强制走 `hf-mirror.com` 并伪装 UA。中断重跑会续传。确认网络能通该镜像。

**Q：生成的 FLAC 微信发不出去？**
A：装了系统 `ffmpeg` 后界面会多一个「下载 MP3」按钮；没有就只给 FLAC，自己用格式工厂转一下。

**Q：能商用吗？**
A：**模型权重是 CC BY-NC 4.0，禁止商用。** 本项目代码（界面与封装）可自由使用，但用模型产出物请遵守其非商用许可。详见[许可证](#许可证与版权)。

**Q：想长期保存某首歌？**
A：界面「下载」存到自己的位置。`outputs/` 只保留最近 20 首，更旧的会自动清理。
